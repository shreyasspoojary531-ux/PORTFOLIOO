# Portfolio Design System Guidelines

## Core Philosophy
- Full black & white palette ONLY (#000000 / #FFFFFF).
- No accent colors, neon, glassmorphism, or artificial gradients.
- High-contrast editorial typography powered by Instrument Serif (Display) + Inter (Body) + Space Grotesk (Mono).
- Motion is subtle, purposeful, and executed using Motion v12 (`motion/react`) with custom cubic-bezier easing `[0.16, 1, 0.3, 1]`.

## Spacing & Rhythm
- Base 8px spatial grid.
- Generous section padding (`py-24` to `py-48`).
- Container max width 1400px with dynamic padding.

## Section Guidelines
1. **Loading Intro**: Title card typography reveal with clip-path mask.
2. **Hero**: Oversized fluid typography, generous whitespace, scroll parallax drift.
3. **About**: Asymmetric storytelling layout with italic pull-quotes.
4. **Projects**: Alternating editorial card layouts.
5. **GitHub**: Typographic stats strip, pinned repo cards, contribution intensity grid, activity feed.
6. **Expertise**: Interactive SVG system architecture blueprint with branch hover state & side panel detail inspection.
7. **Life in Frames**: Bento gallery with grayscale transitions and soft gradient text reveals.
8. **Contact**: Understated large headline, minimal link methods, quiet footer.
